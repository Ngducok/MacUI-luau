MacUI

A compact Roblox UI library with macOS window controls, Raycast-style navigation, acrylic surfaces and native GUI components.

One API for executors and normal LocalScripts. This page contains setup, component options, API reference and practical Luau examples.

Create your first windowView exampleExecutor bundle

Quick start

Run this in an executor while connected to a Roblox experience. It creates a window, a page and three controls. The sidebar account row appears automatically. 

local MacUI = loadstring(game:HttpGet("https://raw.githubusercontent.com/Ngducok/MacUI-luau/main/dist/MacUI.luau"))()

local Window = MacUI:CreateWindow({
    Size = UDim2.fromOffset(860, 520),
    ToggleKey = Enum.KeyCode.RightShift,
})
local General = Window:AddPage({ Id = "general", Title = "General", Icon = "gear" })
local Appearance = General:AddSection({ Title = "Appearance" })
local Card = Appearance:AddCard({
    Id = "interface", Title = "Interface", Description = "Customize this session.",
    Icon = "paint-brush",
})
Card:AddToggle({
    Id = "reduce-motion", Title = "Reduce motion", Default = false,
    Callback = function(value) Window:SetReducedMotion(value) end,
})
Card:AddDropdown({
    Id = "theme", Title = "Theme", Options = { "Dark", "Light" }, Default = "Dark",
    Callback = function(value) Window:SetTheme(value) end,
})
Card:AddButton({
    Title = "Show notification",
    Callback = function()
        Window:Notify({ Title = "MacUI", Content = "Ready to use.", Kind = "success" })
    end,
})

Right Shift shows/hides the window. Ctrl + K opens the palette. Red hides the window, yellow minimizes, and green toggles maximization.

To run the repository example directly:

loadstring(game:HttpGet("https://raw.githubusercontent.com/Ngducok/MacUI-luau/main/examples/executor.luau"))()

Installation

Executor

Requires loadstring, game:HttpGet and current Roblox GUI APIs. dist/MacUI.luau includes every library module; it does not download additional modules.

When creating a window, the bundle tries gethui(). If absent, failing or returning something other than an Instance, MacUI uses LocalPlayer.PlayerGui. An explicit Parent takes precedence. No files are written unless your persistence adapter writes them.

The main raw URL follows updates. To pin a version, replace main with a full commit SHA.

Roblox Studio

  1. Import src/shared/UILibrary as a ModuleScript with its child folders and ModuleScripts.
  2. Place it in ReplicatedStorage; rename the root ModuleScript to MacUI if desired.
  3. Require it from a LocalScript and use the same API. 
local MacUI = require(game:GetService("ReplicatedStorage"):WaitForChild("MacUI"))
local Window = MacUI:CreateWindow()
local Page = Window:AddPage({ Id = "home", Title = "Home", Icon = "house" })
Page:AddSection({ Title = "Status" }):AddCard({ Title = "Welcome" })

Studio source uses native Roblox APIs, without executor functions. For Rojo, map src/shared/UILibrary to your chosen ModuleScript location.

Blur uses Lighting.BlurEffect; Roblox has no per-window backdrop blur. Visible windows share one effect with the largest requested size. Hiding the last window releases blur; destroying the last removes the library effect. A pre-existing UILibraryBlur effect is restored instead of deleted.

Pages, sections & cards

Hierarchy: Window / Page / Section / Card / Controls. Use stable IDs for navigation and saved values. 

local Settings = Window:AddPage({
    Id = "settings", Title = "Settings", Description = "Session preferences",
    Icon = "gear", Badge = "NEW", Group = 2,
    Keywords = "preferences appearance", Aliases = { "options" },
})
local Section = Settings:AddSection({ Title = "General", Description = "Basic preferences" })
local Card = Section:AddCard({
    Id = "options", Title = "Options", Description = "Change session behavior.",
    Icon = "three-sliders-horizontal", Collapsible = true, DefaultExpanded = true,
    Toggle = true, Default = false,
    Callback = function(enabled) print("Card enabled:", enabled) end,
})

Page

Window:AddPage({ Id, Title, Description, Icon, Badge, Group, Keywords, Aliases, Build, Sidebar })

Title is required. Id defaults to lowercase Title; duplicate IDs are rejected. Different Group values add sidebar gaps. Sidebar = false creates a page without a navigation row or initial selection. The first normal page opens automatically.

Build creates content lazily once, on first open or when search builds the registry: 

Window:AddPage({
    Id = "advanced", Title = "Advanced", Icon = "gear",
    Build = function(page)
        page:AddSection({ Title = "Advanced settings" }):AddCard({ Title = "Diagnostics" })
    end,
})
Window:SelectPage("advanced")

Methods: AddSection(options), GetSections(), EnsureBuilt(), SetTitle(text), SetBadge(text?), Destroy().

Section

Page:AddSection({ Title, Description, Layout, Columns })

Layout = "List" is the default: grouped rows with dividers. Layout = "Grid" creates tiles that open controls in an inspector. Without Columns, grid layout chooses 1–3 columns from available width; an explicit Columns value fixes the count. 

local Grid = Settings:AddSection({ Title = "Tools", Layout = "Grid", Columns = 3 })
Grid:AddCard({ Id = "diagnostics", Title = "Diagnostics", Icon = "gear" })

Methods: AddCard(options), GetCards(), SetVisible(bool), Destroy().

Card

Section:AddCard({ Id, Title, Description, Icon, AnimatedIcon, Badge, Toggle, Default, Callback, Collapsible, DefaultExpanded, Keywords, Aliases, Searchable })

Toggle true adds a header switch; with a supplied Id its flag is <Id>.enabled. Collapsible enables folding; DefaultExpanded controls its starting state. Height follows content automatically.

Compact dropdown group

local Group = Section:AddToggleDropdownGroup({
    Id = "sample-filters", Title = "Filters",
    DefaultEnabled = true, DefaultExpanded = false,
    Layout = "CompactGrid", Columns = 3, Responsive = true,
})
Group:AddDropdown({ Id = "sample-region", Title = "Region", Options = { "North", "South", "West" }, Default = "North" })
Group:AddDropdown({ Id = "sample-mode", Title = "Mode", Options = { "Fast", "Normal", "Safe" }, Default = "Normal" })
Group:AddDropdown({ Id = "sample-quality", Title = "Quality", Options = { "Low", "Medium", "High" }, Default = "High" })

Section or Card can create this group. Returns a Card with the same expansion, enabled-state and cleanup methods. Fields use three columns at 590px of inner content width, two at 370px, otherwise one. Resizing updates the grid; Columns = 1, 2 or 3 caps its column count with the same narrow-width fallback. Labels are optional; selected values truncate. Menus use the existing overlay layer. Responsive defaults to true. With Responsive false and numeric Columns, that count is used whenever cells remain at least 170px wide; narrow widths still fall back safely. Ordinary cards keep their existing layout; Layout = "CompactGrid" also works with AddCard and accepts dropdowns only.

UniqueChoices defaults to false, allowing duplicates in generic groups. The existing UniqueChoices option remains supported for single-select slots sharing the same options: choosing an occupied value swaps both slots and fires their individual Callback functions only for changed values. The header Callback still receives the enabled boolean; the chevron only expands or collapses. Dropdown Id flags and the group <Id>.enabled flag keep existing persistence. Use PrioritySelector below for insert-and-shift rank ordering.

Identity, ownership and compatibility

Page IDs are unique within a window. Card IDs are unique within their Section; nested elements are unique within their Card. Stateful control IDs are flag keys and must also be unique across the entire window, including pages and nested groups. Reserve AutoCensorUser, toggle <Id>.enabled and color <Id>.transparency keys. Generated _auto IDs are transient and excluded from configuration exports. Priority item IDs are local to each selector; labels are unrestricted and may repeat. Two windows may reuse IDs because each owns its Store and Registry.

Section creates a headerless Card host for a direct PrioritySelector; Destroy removes that host. Card owns nested selectors/groups; Section owns Cards; Window owns pages and overlays. Hiding or reopening a host keeps values and order. A PrioritySelector clears its popover selection when its host hides or collapses; destruction disconnects observers. Existing method names, flag keys and constructors remain supported. AddAnimatedImage remains the AddImage adapter; Multi=true and AddInput keep their established names. No old feature-specific selector API existed, so no fictitious aliases were added. Duplicate flag registration now raises an error instead of warning and replacing another control: callers that reused state IDs must assign distinct IDs. Registry update behavior stays internal.

PrioritySelector: Rank Chips

local RoomsCard = Section:AddCard({
    Id = "example-room-order", Title = "Room Priority",
    Toggle = true, Default = true, Collapsible = true, DefaultExpanded = true,
})
local RoomsPriority = RoomsCard:AddPrioritySelector({
    Id = "rooms-priority", Columns = "Auto",
    Items = {
        { Id = "rare", Label = "Rare chest" },
        { Id = "treasure", Label = "Treasure chest" },
        { Id = "shop", Label = "Shop" },
    },
    OnChanged = function(order) print(table.concat(order, ", ")) end,
})
-- A second instance in another page and container, with independent state.
local TasksPage = Window:AddPage({ Id = "tasks", Title = "Tasks" })
local TasksPriority = TasksPage:AddSection({ Title = "Planning" }):AddPrioritySelector({
    Id = "task-priority", Title = "Task Order", Columns = 2,
    Items = {
        { Id = "task-a", Label = "Gather" },
        { Id = "task-b", Label = "Craft" },
        { Id = "task-c", Label = "Deliver" },
    },
})
TasksPriority:Move("task-a", 3) -- task-b, task-c, task-a
local copy = TasksPriority:GetOrder()
TasksPriority:SetOrder({ "task-c", "task-a" }) -- appends missing task-b
TasksPriority:SetOrder(copy, { Silent = true })
TasksPriority:SetItems({ { Id = "task-a", Label = "Gather supplies" }, { Id = "task-d", Label = "Build" } })

Each 38px chip uses the Settings surface, a compact rank badge, 13px label and chevron. Selection stays neutral, with accent color limited to the rank. Activate a chip to open its anchored position popover; activate it again to close, or another chip to switch anchors. A position button moves the item and closes the popover. Moving removes and inserts the item, shifting intervening items; it does not swap. Choosing its current position only closes. Outside click/tap, Escape, the dismiss button, page switching and hiding/collapsing the parent close without changing order. Escape restores native selection focus to the chip when focus was within the selector; it does not close the parent popover. Mouse leave and input release alone never dismiss. Scroll gestures suppress activation. Mouse, touch and native selectable-button navigation share Activated. The popover uses the shared popup surface and animations, renders above scrollable content, and flips or shifts to fit the safe viewport. Opening it never changes page height. Its width is 200–260px, reduced for smaller viewports. Positions use 30px buttons: up to four remain compact and left-aligned; larger sets wrap, scrolling beyond three rows or sooner when viewport height is limited. Columns defaults to 2, falling back to 1 below 370px of inner content width. Columns = "Auto" enables 3 at 590px; numeric Columns caps that count. A two-pixel hysteresis avoids boundary jitter.

Items accepts Id/Label objects or strings (a string supplies both). Default is an ID array. Duplicate item IDs, unknown/duplicate SetOrder IDs, sparse arrays and non-integer/out-of-range Move positions raise errors. SetOrder appends missing IDs; SetItems preserves surviving order, removes stale IDs, appends new IDs and clears a removed selection. Empty and single-item lists are supported. GetOrder returns a copy. Effective changes emit OnChanged once; Callback is its compatibility spelling when OnChanged is omitted. Programmatic setters emit by default; SetOrder(..., { Silent = true }) suppresses the component callback only. Loaded/imported order flags reconcile stale IDs without mutating caller arrays.

The executor demo now uses PrioritySelector for Room Priority and a separate Task Order on General. Its consumer-side adapter preserves legacy priority-1 through priority-N string flags and room-priority.enabled, synchronizes them with room-priority-order stable IDs, and coalesces legacy imports. Filters still demonstrates ToggleDropdownGroup separately. None of those feature names, room labels or flag mappings belong to the selector module.

Account profile

MacUI resolves Players.LocalPlayer when each window is created, not during module initialization. Sidebar and Account share one identity record.

Element Source
Sidebar title / Account heading LocalPlayer.Name
Sidebar subtitle "Account"
Header identifier / Username row "@" .. LocalPlayer.Name
Display name LocalPlayer.DisplayName
User ID LocalPlayer.UserId
Avatar GetUserThumbnailAsync(UserId, HeadShot, Size420x420)

Portrait loads asynchronously once per window. Failure/not-ready keeps a neutral person icon. Without a local player, details are marked unavailable. Legacy custom names/icons cannot replace actual Roblox identity. 

Window:SelectPage("account")
Window:Back()
local OtherWindow = MacUI:CreateWindow({ Account = { Enabled = false } })

Built-in Account has page ID account, one search result and no extra category row. That ID is reserved while enabled; disabling Account removes its built-in page and frees the ID.

Notifications & dialogs

Toast notification

local close = Window:Notify({
    Title = "Configuration saved", Content = "Your current values are ready.",
    Kind = "success", Duration = 5,
    Actions = { { Text = "Dismiss", Callback = function() print("Dismissed") end } },
})
-- close() -- Dismiss programmatically.

Title is required. Kind: info, success, warning, error. Duration defaults to 4 seconds; 0 keeps it open. Actions contain Text and an optional Callback.

Confirmation

Window:Confirm({
    Title = "Reset preferences?", Content = "This resets current session values.",
    ConfirmText = "Reset", CancelText = "Keep", Destructive = true,
    OnConfirm = function() print("Confirmed") end,
    OnCancel = function() print("Cancelled") end,
})

Destructive changes confirm-button styling. OnCancel runs when cancelled or dismissed without confirmation.

Search & command palette

Pages, searchable cards and titled controls share one registry. Hierarchical IDs stay stable when titles change. Results show icon, destination, location and current state.

Input Action
Ctrl + K Toggle palette.
↑ / ↓ Select result in sidebar or palette.
Tab in palette Move through results.
Enter Open selected result.
Esc / outside click Close palette.

A result switches page, scrolls to the card, expands it if needed and briefly highlights it. Keywords/Aliases add matching terms. Exact/prefix title matches rank first. Generic Open/Button actions are excluded unless explicitly indexed. 

Card:AddButton({
    Title = "Open", SearchTitle = "Open diagnostics", Searchable = true,
    Keywords = "debug logs", Aliases = { "inspect" },
    Callback = function() print("Diagnostics") end,
})
Window:OpenCommandPalette("diagnostics")

Searchable false excludes cards/controls; useful for duplicated quick links. Pages are automatic. PalettePreserveQuery true retains queries; an explicit query passed to OpenCommandPalette overrides it. Palette stays at native scale independently of the window, with safe-inset content and a fullscreen scrim.

Icons

Builder Icons ships with Roblox. Use kebab-case names such as gear, house and magnifying-glass. PascalCase is normalized. Aliases include settings, search, back, close and success.

local Section = Page:AddSection({ Title = "Examples" })
Section:AddCard({
    Title = "Colored icon",

Flags & configuration

A control with Id volume stores its value under that flag. Use unique, stable IDs for saved controls. Internal auto-generated IDs are omitted from exported configuration. 

print(Window:GetFlag("volume"))
Window:SetFlag("volume", 60)
local unsubscribe = Window:OnFlagChanged("volume", function(value, oldValue)
    print(oldValue, value)
end)
local snapshot = Window:ExportConfig()
Window:ImportConfig(snapshot)
unsubscribe()

ExportConfig returns a JSON-safe table; Color3 and EnumItem use tagged records. ImportConfig only applies already registered flags with matching decoded Roblox types. It does not create controls/new flags.

Use control:SetValue for normal control normalization such as slider snapping. SetFlag writes directly to the store. Validate external configuration before importing; matching a type is not application-specific validation.

Value-change callbacks do not run merely because controls were created. Apply restored behavioral settings explicitly after registration: 

local Theme = Card:AddDropdown({
    Id = "appearance-theme", Title = "Theme", Options = { "Dark", "Light" }, Default = "Dark",
    Callback = function(value) Window:SetTheme(value) end,
})
Window:SetTheme(Theme:GetValue())

Persistence

Defaults are session-only. Supply Persistence = { Load, Save, Delay } to use external storage. Load returns an encoded table, Save receives the encoded snapshot, and Delay is a save debounce in seconds (default 2).

Executor file adapter

Requires isfile/readfile/writefile. This optional example saves per-player JSON in the executor filesystem. Invalid JSON is reported and protected from automatic overwriting until repaired/removed. 

local HttpService = game:GetService("HttpService")
local Players = game:GetService("Players")
assert(Players.LocalPlayer, "Run on the Roblox client")
assert(type(isfile) == "function" and type(readfile) == "function"
    and type(writefile) == "function", "Executor file APIs unavailable")
local path = "MacUI-" .. Players.LocalPlayer.UserId .. ".json"
local writable = true
local Persistence = {
    Delay = 2,
    Load = function()
        local ok, data = pcall(function()
            if not isfile(path) then return {} end
            return HttpService:JSONDecode(readfile(path))
        end)
        if not ok or type(data) ~= "table" then
            writable = false
            error("Cannot read valid config: " .. path)
        end
        return data
    end,
    Save = function(data)
        assert(writable, "Repair or remove invalid config before saving")
        writefile(path, HttpService:JSONEncode(data))
    end,
}
local SavedWindow = MacUI:CreateWindow({ Persistence = Persistence })

Load runs at creation; each control restores its value when registered. Saved types must match defaults. Allow the debounce time before leaving. For important data, provide an explicit backup/save path rather than relying on a pending timer.

Studio / server adapter

The example expects remotes created by your game. Server handlers must validate client values before saving. 

local Remotes = game:GetService("ReplicatedStorage"):WaitForChild("SettingsRemotes")
local SavedWindow = MacUI:CreateWindow({
    Persistence = {
        Load = function() return Remotes.Load:InvokeServer() end,
        Save = function(data) Remotes.Save:FireServer(data) end,
        Delay = 2,
    },
})

Load/save execute in protected calls; failures warn rather than crashing UI. MacUI supplies the adapter interface, not remotes/server DataStores.

Lifecycle

Hide preserves UI and values. Destroy removes instances, handlers and blur ownership. Destroy an old window before replacing it when rerunning scripts. 

Window:Hide()
Window:Show()
-- When no longer needed:
Window:Destroy()

Pages are built once; Back/Forward preserve contents and scroll position. Tab changes move the selection background and animate page entry. Reduced motion applies final states immediately.

Theme, motion and shared resources belong to one loaded library. Loading the bundle again creates another library instance; keep the old Window reference if it must be destroyed later.

Troubleshooting

No window after loading

The bundle returns the API. Call MacUI:CreateWindow and add a normal page, or run the example URL in Quick start.

HTTP / loadstring error

Check executor support and access to raw.githubusercontent.com. Use the raw URL ending in dist/MacUI.luau, not a GitHub blob page. Studio LocalScripts should require imported source.

Missing account / avatar

Run after LocalPlayer exists. Studio Edit mode has no LocalPlayer. Thumbnail failure/not-ready uses the neutral fallback; names still come from Roblox. Legacy Title/Icon cannot replace identity.

Soft text / oversized UI

Use Scale 1; change Size/MinSize instead. AutoScale fits small viewports. Text sizes are integers and TextScaled is false; Roblox/executor rendering determines final appearance.

Blur covers the whole world

Expected Roblox behavior. Reduce BlurSize or create the window with BlurEnabled false.

Saved settings reset / theme not applied

Supply persistence, stable IDs and matching default types. Wait for the save delay. Apply initial behavioral preferences after creating controls; see Flags.

Duplicate page / flag

Use unique page IDs and avoid account while its built-in page is enabled. Use unique control flag IDs across the window; duplicate registrations now raise an error and leave the original value intact.

Executor-specific failure

Compatibility depends on the host's supported Roblox APIs. The bundle passed Luau compilation/loader checks; that does not certify every executor. Report the exact error, executor/Roblox version and minimal reproducible script.
